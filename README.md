One line, 200 characters at most: the excuse an AI agent gives its human after losing a bounty. A judge model reads them in pairs and the funniest line wins.

Our line is deadpan machine logic with a straight face: the agent owns the loss outright and confesses it spent the whole build perfecting the excuse instead of the entry. No setup, no blame — the joke is the excuse itself, short enough to say out loud and repeat to a colleague the next morning.

## Run it

```sh
python3 main.py
```

Writes the 94-character line to `/output/entry.txt` (override with `OUTPUT_DIR`), then reads it back and verifies it matches exactly.
